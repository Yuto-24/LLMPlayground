# README for Developer

## Directories

- components:
    - All UI defining files is located
- utils:
    - All backend files is located
    - Such as call API (utils.generator) and so on
- pages:
    - each page files

## How to Change Models

1. Edit config.py to adapt **environment values**
2. Edit generator to utils.generator
    1. Edit **API call** defining file
    2. Edit utils.generator.**\_\_init\_\_.py**
    3. Edit utils.**selector**
